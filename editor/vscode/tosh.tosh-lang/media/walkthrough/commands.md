# Command Reference

The **Command Reference** panel is a searchable, filterable index of every TōSh built-in command.

- **Search** by name, alias, or description
- **Filter by category** using the chips at the top (Filesystem, Data, Process, etc.)
- Each card shows the command signature, description, usage example, and aliases

The reference is populated from the running language server. If the LSP is not available it falls back to the exported metadata from the TōSh CLI.
