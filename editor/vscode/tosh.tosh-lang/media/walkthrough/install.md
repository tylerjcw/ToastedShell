# Install TōSh

Download the latest TōSh release for your platform and make sure the `tosh` executable is on your `PATH`.

**Quick check:** Click **Check Installation** in the step on the left — you should see the installed version.

**If TōSh is not on your PATH**, either:
- Add it to your shell's `PATH` variable, or
- Set the `tosh.terminal.path` setting to the full path of the executable.

```
tosh --version
```
