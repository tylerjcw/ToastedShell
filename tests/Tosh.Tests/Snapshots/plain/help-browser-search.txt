╭ ToastedShell ───────────────────────╮ ╭ seek [BuiltIn] ──────────────────────────────────────────────────────────────╮
│  ▾ Filesystem                       │ │BuiltIn • Filesystem                                                          │
│›   seek                             │ │                                                                              │
│  ▾ Network                          │ │Moves an open managed file handle to a new position and returns the handle for│
│    ping                             │ │continued piping.                                                             │
│                                     │ │                                                                              │
│                                     │ │Usage                                                                         │
│                                     │ │  seek [handle] <offset> [begin|current|end]                                  │
│                                     │ │                                                                              │
│                                     │ │Arguments                                                                     │
│                                     │ │  handle (optional)                                                           │
│                                     │ │    The managed file handle to reposition.                                    │
│                                     │ │  offset : long                                                               │
│                                     │ │    The byte offset to seek to or by.                                         │
│                                     │ │  origin (optional)                                                           │
│                                     │ │    The seek origin: begin, current, or end. Defaults to begin.               │
│                                     │ │                                                                              │
│                                     │ │Pipeline Input                                                                │
│                                     │ │  object: yes  scalar: no  path-like: no  collection: no                      │
│                                     │ │    Consumes a piped file handle when no explicit handle argument is supplied.│
│                                     │ │                                                                              │
│                                     │ │Output                                                                        │
│                                     │ │  Moves the handle and returns it so you can continue piping into `read-from`,│
│                                     │ │    `read-line-from`, `read-to-end`, or `copy-to`.                            │
│                                     │ │                                                                              │
│                                     │ │Examples                                                                      │
│                                     │ │    seek $handle 0 begin                                                      │
│                                     │ │    $handle | seek 128 current                                                │
│                                     │ │                                                                              │
│                                     │ │Notes                                                                         │
│                                     │ │  These commands work with managed file handles returned by `open-file` or by │
│                                     │ │    `FileSystemEntry` methods like `OpenText()` and `OpenRead()`. `seek`      │
│                                     │ │    returns the handle so you can keep piping through the stream workflow,    │
│                                     │ │    while `copy-to` copies from one compatible handle into another.           │
