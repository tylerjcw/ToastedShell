> **Withdrawn 2026-09-25** under `TOAST-ARCH-01`: Tōast has no compiler ([COMPILER_DECOMMISSIONING_PLAN.md](../../COMPILER_DECOMMISSIONING_PLAN.md)). The tier model is withdrawn with the compiler; builtin dispatch has one path, the interpreter's.

> Status as filed: Proposed — filed 2026-08-13

## Problem

Builtin command dispatch at Tier 1

## Acceptance

`commands.builtin-host-dispatch` is Tier 2: every builtin routes through the host at runtime. For a native target this is the stdlib port, and it is the single largest item in the native estimate — several hundred commands currently implemented in C#. Wants a decision first on which commands belong to the language core (Bucket A/B in `docs/COMPILED_TOSH.md`) versus the shell, because only the former need a native implementation.
