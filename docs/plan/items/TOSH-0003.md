## Problem

The packaging expression of the separation. `packaging/archlinux/` currently builds a
single `tosh` package containing everything.

This is the test the separation cannot fake. Assemblies can be moved and directories
renamed while the halves remain inseparable in practice; a package boundary either
installs without the other half or it does not.

## Acceptance

- [ ] A `toast` package builds and installs on its own
- [ ] `tosh` depends on `toast` rather than vendoring it
- [ ] **A machine with `toast` installed and `tosh` absent runs a `.toast` script** — the whole point
- [ ] Tōme and Crumb depend on `toast` rather than on `tosh`
- [ ] Upgrading from the single package to the split pair leaves a working logon shell

## Notes

Do this **after** `TOAST-0006` settles which assemblies land on which side, or the
package split has to be redone the first time an assembly moves.

The upgrade path is the risk, not the build: TōSh is a logon shell on at least one
machine. A package split that leaves someone without a shell is not recoverable from
inside that shell.
