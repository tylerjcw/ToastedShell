## Problem

Two problems, one cause: **nothing runs the examples.**

Eleven of the 28 had not been touched since April, and there is no test that executes
any of them, so an example can stop working and nothing says so. Several were working
files rather than curated examples — `argtest`, `compile-test`, `hello.tosh` at one
line — and some have since been removed by hand.

The proposal is to replace the loose collection with a small example *library* plus
scripts that call it, so the examples demonstrate composition rather than each
restating setup, and possibly an interactive driver.

## Acceptance

- [ ] Non-GUI examples execute in the suite and are asserted to exit 0
- [ ] Curated examples are separated from working files, and working files leave `examples/`
- [ ] Shared setup lives in an example library rather than being restated per file
- [ ] GUI examples (`sdl_test`, `gl_test`, `gtk_test`) are excluded from the automated run and marked as manual
- [ ] `examples/compile-test.tosh` resolved, since it exercises a component being frozen

## Notes

Sequence after the file split: `TOAST-0006` and `TOAST-0007` will move what the
examples import, so rewriting them first means rewriting them twice.

The ignore rules added in `d153eee` already stop compiled output being committed back
into `examples/`, which is how 5.5 MB of stripped ELF and five runtime assemblies came
to be tracked there for months.
