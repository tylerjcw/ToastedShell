> Status as filed: Proposed — filed 2026-08-13

## Problem

Native backend emitting C

## Acceptance

Emit C and invoke the system compiler rather than emitting object code or LLVM IR: every platform optimiser for free, trivial bootstrapping, debuggable output, and the shortest path to the cross-platform goal. Nim and Vala both ship this way. Genuinely the smallest of the native work items — it is gated by `TS-P3-15` through `TS-P3-21`, not the reverse, which is the opposite of how the project is usually imagined.
