## Problem

M1–M4 of the external-program I/O compact landed 2026-05-13; **M5 (polish) was
deferred** and is what remains.

The original gap: there was no documented way for an external program to render
structured output to TōSh *and* read interactive input from the user at the same time.
The forcing example was `crumb -S <many AUR pkgs>` at a bare prompt. Crumb sat on the
`KnownStructuredCommands` allowlist, which forces the piped path so TōSh can parse TSSP
frames — but that path also redirects stdin and never calls `tcsetpgrp`, so the child
opened `/dev/tty` while TōSh's REPL still owned the controlling terminal. Every
keystroke was contended, and prompts accepted no input.

**The mitigation is still in place**: the allowlist is empty, so interactive children
take the full passthrough path and TSSP rendering for `crumb` at a bare prompt stays
suspended. That is the deferred cost — it works, but a first-party tool cannot render
structured output interactively.

## Acceptance

- [ ] An interactive child can render TSSP frames *and* read from the user in the same session
- [ ] `crumb -S` at a bare prompt: prompts work, status streams live, the install plan renders as a TōSh-styled table
- [ ] `crumb -Ss dotnet \| from json` still produces structured records
- [ ] A second small consumer demonstrates the contract end to end
- [ ] The `KnownStructuredCommands` allowlist can be repopulated without reintroducing the contended-terminal defect

## Notes

Explicit non-goals: no pty multiplexer or terminal-emulator layer, and no forcing every
external command to participate — programs that ignore the environment variables must
keep working exactly as they do today.

`Tosh.Client` is the surface (see `TSSP.md` §11) and `examples/tsspdemo` is the
canonical second-consumer demo, which is why that demo is one of the few things under
`examples/` that is real source rather than a scratch file.

Deferred rather than open: the mitigation works, and this competes with the separation
work. Revisit when TSSP rendering for first-party tools becomes worth the plumbing.
