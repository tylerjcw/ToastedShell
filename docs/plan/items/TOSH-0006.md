## Problem

On a UTC−4 machine, a value written `12:00:00` is displayed as `08:00:00`:

```tosh
[{| When = (new DateTime(2026, 8, 17, 12, 0, 0)) |}]
# │ When │ 2026-08-17 08:00:00 │
```

The `DateTime` display profile's default `Local` mode calls `value.ToLocalTime()`, and
.NET's `ToLocalTime` **assumes an `Unspecified` kind means UTC** and converts from it. No
timezone was stated, so none should be applied.

**The file already contains the right answer.** `ToDisplayInstant`, twenty lines below,
treats `Unspecified` as *Local* — which is what a wall-clock literal means — and the
`Relative` and `Unix` modes go through it and are correct. Only `Local` reaches for
`ToLocalTime` directly, so one mode disagrees with the other three about the same question.

`FormatDateTimeOffset`'s `ToLocalTime` is **not** affected: a `DateTimeOffset` carries its
offset, so converting it is unambiguous.

## Acceptance

- [x] A `DateTime` with `Kind = Unspecified` displays its own clock reading, unshifted
- [x] A `DateTime` with `Kind = Utc` still converts to local time
- [x] `Relative` and `Unix` are unchanged — they already went through `ToDisplayInstant`
- [x] `DateTimeOffset` display is unchanged
- [x] A negative control: 2 of 4 fail with the profile reverted; the other two are the
      `Utc` and `Local` cases, written to pass either way

## Resolution — 2026-08-17

One line. `TemporalDisplayMode.Local` now goes through `ToDisplayInstant` instead of
reaching for `value.ToLocalTime()`, which is what the two modes below it already did.

The fix was **removing a disagreement rather than adding a rule** — the correct reading of
an `Unspecified` kind was already written down twenty lines away and used by two of the four
modes. That is worth noting for the next one of these: a defect that looks like a missing
decision is sometimes a decision already made and not applied everywhere.

A test pins that display and rendering agree about the *instant*. They may still differ in
format — a profile can show relative time or a Unix stamp, and that is what profiles are
for — but not about which moment they are describing.
