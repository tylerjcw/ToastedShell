## Problem

Native runtime: GC, object layout, and startup budget

## Acceptance

Choose and integrate a collector — Boehm is the pragmatic start, conservative and cross-platform; refcounting leaks cycles; writing one is a project in itself. Define the native object header and value representation, including the string encoding decision (UTF-8 natively versus UTF-16 in .NET, and who pays to transcode at the boundary). Set an explicit startup budget: the whole justification for a native target is 120 ms becoming single-digit milliseconds, so anything dynamically loaded at startup has to be argued for.
