> Status as filed: Proposed

## Problem

Uniform thrown-value protocol

## Acceptance

Wrap thrown non-exception values so `catch (e)` always exposes `.Message` and a kind discriminator; today `throw "boom"` followed by `$e.Message` is a runtime error.
