> Status as filed: Completed — Stages A–D and Scientific Computing Architecture implemented with full test coverage (7,958 passing tests, zero failures).

## Problem

Unify `StorageSize`/`TemporalAmount` with the Quantity unit system, extend physical units to top-tier scientific computing, and integrate physical units with the built-in Computer Algebra System (CAS).

## Acceptance

The source of truth is [`UNIT_SYSTEM_STABILIZATION.md`](UNIT_SYSTEM_STABILIZATION.md) and [`SCIENTIFIC_COMPUTING_AND_CAS_DESIGN.md`](../../SCIENTIFIC_COMPUTING_AND_CAS_DESIGN.md).

Implemented and validated:
1. **Exact Rational Exponents**:
   - `RationalExponent` exact rational arithmetic struct with GCD reduction and normalization.
   - `UnitExpression` upgraded to fractional exponents (`m^(1/2)`, `s^(-1/2)`), root extraction (`.Root(n)`), and exact powers.
2. **Semantic Kind Separation**:
   - `SemanticKind` metadata on `UnitDefinition`, `NamedQuantityTypes`, and `Quantity` preventing invalid dimension-sharing additions/subtractions (e.g., Energy vs. Torque).
3. **Unit Parser & Lexer Upgrades**:
   - Support for parenthesized groups, radicals (`sqrt(...)`), and fractional powers in `UnitExpressionParser` and `ToshLexer` (e.g., `nV/sqrt(Hz)`).
4. **Vectorized SIMD Memory Buffers**:
   - Contiguous `QuantityArray` with `System.Numerics.Vector<double>` SIMD element-wise arithmetic, scalar operations, reductions (`Sum`, `Mean`, `Min`, `Max`), fast slicing, and indexing.
5. **CAS & Symbolic Units Integration**:
   - `SymQuantity` immutable symbolic expression node.
   - Exact dimensional calculus in `Simplifier`, `diff`, `solve`, and `eval`.
   - Automatic unit cancellation (`(10 m * x)/(2 m) => 5*x`), like-term grouping (`10 m * x + 20 m * x => (30 m)*x`), and equation solving with physical units.
