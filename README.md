# TōSh

**A .NET-native shell, REPL, and scripting language with object-first pipelines.**

TōSh (ToastedShell, `tosh`) is a Unix-style interactive shell, REPL, and
scripting language built on .NET 10. It moves real CLR objects through
the pipeline — `FileInfo`, `DateTimeOffset`, `Process`, `IPAddress`,
`UnixFileMode` — and renders them with a typed display system instead
of collapsing every value to a string the way POSIX shells do.

```tosh
ls -la | where _.Type == file | sort-by Size | first 5 | get { Name, Size, Modified }

ip addr | where _.State == up | get _.Addresses

ps | group-by User | each { {| User: $_.Key, Total: ($_.Value | sum CpuPercent) |} }
```

The same script runs three ways:

1. **Interactive REPL** — colour-aware line editor with completions, hover, and inline diagnostics.
2. **Scripts** — `#!/usr/bin/env tosh`, full LSP / MCP tooling.
3. **Compiled IL** — `tosh --compile` lowers a hot subset of the language into a real .NET assembly (see [docs/COMPILED_TOSH.md](docs/COMPILED_TOSH.md)).

---

## Highlights

- **Object pipelines.** Pipeline values are real CLR objects. Display is a projection, never the value.
- **~209 typed built-ins.** `ls`, `ps`, `df`, `find`, `grep`, `cat`, plus structured Linux adapters for `ip`, `lsblk`, `findmnt`, `lscpu`, `lsfd`, `lsipc`, `journalctl`, and `systemctl`.
- **First-class .NET interop.** `new`, `call`, `cast`, `members`, `describe-type`, native interop via `require native`, `bind`, and `read-buffer` / `write-buffer`.
- **A real language, not a config DSL.** Functions, modules, classes, records, enums, generics, operator overloading, pattern matching, comprehensions, lazy sequences, runes (Boo-style AST macros), structured concurrency primitives.
- **Editor tooling.** LSP server (`tosh-lsp`), MCP server (`tosh-mcp`) for AI agents, VS Code extension with syntax / hover / completion / formatter, and a GtkSourceView language definition.
- **Specified.** A 4 400-line LaTeX language specification in [docs/spec/](docs/spec/) plus an autogenerated command reference.

## Install

### Arch Linux

```bash
git clone https://github.com/tylerjcw/ToastedShell.git tosh && cd tosh
scripts/build.tosh install              # builds & installs tosh, tosh-lsp, tosh-mcp
scripts/build.tosh install --linuxDesktop  # also registers MIME, icons, .desktop entries
```

### From source (any platform)

Requires the .NET 10 SDK.

```bash
git clone https://github.com/tylerjcw/ToastedShell.git tosh && cd tosh
dotnet build Tosh.slnx -c Release
dotnet run  --project src/Tosh.Cli -c Release
```

To produce a single self-contained binary:

```bash
scripts/build.tosh publish              # writes artifacts/publish/tosh
```

## Quick Tour

```tosh
# Typed pipelines — Size is bytes, Modified is DateTimeOffset
ls -la | where _.Size > 1MB | sort-by Modified | last 10

# String interpolation, modules, classes
record Vec(x, y) {
    func +(rhs) => new Vec($this.x + $rhs.x, $this.y + $rhs.y)
}
echo (new Vec(1, 2) + new Vec(3, 4))    # Vec { x: 4, y: 6 }

# Comprehensions and lazy ranges
var primes = (n <| for n in 2..  if not (2..(int (Math.Sqrt $n)) | where { $n % _ == 0 } | first))
$primes | first 25

# CLR + native interop
new System.Net.IPEndPoint 127.0.0.1 8080
require native libc
bind libc int getpid()
getpid

# Full-screen tooling
help browse              # paginated, searchable command index
config browse prompt     # live preview of prompt segments
```

See [examples/common_tasks/](examples/common_tasks/) for end-to-end recipes.

## CLI

```
tosh                              # interactive REPL
tosh -c "command"                 # one-liner
tosh script.tosh                  # run a script
tosh --login | --safe | --no-profile
tosh --compile script.tosh -o out.dll
tosh --dump-builtins              # full machine-readable command catalogue (JSON)
```

A complete flag reference is in [AGENTS.md](AGENTS.md#cli-flags).

## Editor & Agent Integration

| Surface              | Binary       | Purpose                                                              |
|----------------------|--------------|----------------------------------------------------------------------|
| LSP server           | `tosh-lsp`   | hover, completion, signature help, document symbols, diagnostics     |
| MCP server           | `tosh-mcp`   | exposes `lsp_*`, `run_snippet`, `explain_error`, `command_metadata`  |
| VS Code extension    | `tosh.tosh-lang` | syntax, snippets, walkthrough, marketplace-publishable VSIX       |
| GtkSourceView        | `tosh.lang`  | GNOME / GTK editors (gedit, gnome-builder, ...)                      |

Sync the bundled VS Code extension into your local VS Code:

```bash
scripts/build.tosh sync         # mirrors editor/vscode/tosh.tosh-lang into ~/.vscode/extensions
```

Details: [docs/EDITOR_SUPPORT.md](docs/EDITOR_SUPPORT.md).

## Building, Testing, Benchmarking

`scripts/build.tosh` dispatches every common workflow:

```bash
scripts/build.tosh publish      # version-bump, package, install
scripts/build.tosh test         # full test suite
scripts/build.tosh test --group lsp
scripts/build.tosh check        # CI gate: build solution + smoke test
scripts/build.tosh bench        # benchmark publish configurations
scripts/build.tosh clean        # remove bin/obj/TestResults/artifacts
scripts/build.tosh info         # repo digest (version, git, last test/bench)
scripts/build.tosh errors       # surface diagnostic codes from latest build
scripts/build.tosh vsix         # package + install VS Code extension
scripts/build.tosh all          # clean → check → publish → install → vsix
```

`dotnet test Tosh.slnx` and `dotnet run --project src/Tosh.Cli` work without it.

## Performance

On AMD Ryzen 9 9950X / .NET 10:

| Workload                                       | Mean   | Notes                                |
|------------------------------------------------|-------:|--------------------------------------|
| `echo hello` (parse + bind + eval)             | 3.2 µs | trivial pipeline                     |
| 5-stage pipeline (`Tiny` parse + bind)         | ~3 µs  | typical REPL line                    |
| `1..100 \| where >50 \| sort \| first 5`       | 151 µs | the obvious target for the IL backend |

Full numbers: [docs/BENCHMARKS.md](docs/BENCHMARKS.md). The IL backend (`tosh --compile`) targets boxing-heavy pipelines like the last row.

## Status

TōSh is mature as an exploratory REPL, a scripting shell, and a daily
side shell for real work. It is not yet hardened as a default login
shell — open work centres on startup / login-shell edge cases, common-command
parity polish, and the IL backend. See [docs/ROADMAP.md](docs/ROADMAP.md)
and [docs/plan/](docs/plan/README.md).
